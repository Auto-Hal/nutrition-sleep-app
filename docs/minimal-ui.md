# 色配分と情報の強弱を整えたデザイン見直し

機能リリース後のレビュー用デザイン変更。「余白と文字を整えたミニマルなデザイン」を軸に、前案で弱かった色の役割と操作・データの区別を改善する。プロフィール同期の修正2件も取り込み、本番の機能を引き継ぐ。このデザインは本番へ反映していない。

## 変更

- 暖かいオフホワイト（#f3f1eb）、白いデータカード、ネイビーの文字（#202c3c）を基調にする。グリーンは栄養・記録、ブルーは睡眠に使い、警告のアンバーと役割を分ける。
- ChatGPTの登録カードと下部ナビをネイビーにし、選択や主要操作を淡いジェイドで強調する。背景全体へ緑を広げず、数値を読む面は明るく保つ。
- 栄養の目安量に薄い面を敷き、平均との区別をつける。睡眠の平均時間を濃色の大きな指標として表示し、就寝・起床やステージの詳細を下へ整理する。
- ページ見出し、セクション、数値、補足文の文字サイズと太さを整理。期間平均を主に、推奨量・目安量を比較できる位置に表示する。
- 7・30・90日の選択は濃色で現在地を示す。下部ナビは画面から少し離した固定配置とし、端末の安全領域を避ける。
- ナビゲーションと登録導線に同じ線幅のSVGアイコンを使用。外部フォント・画像・アイコンの依存パッケージは追加しない。
- アカウント情報と既存のログアウト操作を右上の開閉メニューにまとめる。未同期データの確認・保持処理と認証の動作は引き継ぐ。
- ページ見出しに統一した線画アイコンを置く。設定の入力欄は16px・高さ48px、ボタンは最低44pxとし、プロフィールの項目や保存・復旧処理を維持する。
- PWAの背景色とテーマ色を画面にそろえる。

Todayには栄養素の不足や分析ガイドを追加しない。全18栄養素の平均・プロフィール別目安量、既知・評価日数、日別・食品別の内訳、睡眠の平均・経過・詳細を維持する。今回の追加デザイン変更は計算、保存API、マイグレーション、アクセス権限を変更しない。
